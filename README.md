Vice Cover Maker is an offline, single-page GTA 6 style cover studio. Upload your own photos, arrange them in one of five multi-panel layouts, pick a colour grade (Sunset, Neon, Vice City, Gold or Night), add a big Anton title with a neon Pacifico subtitle, then export a finished cover as PNG in three sizes: 1080×1080, 1080×1350 or 1920×1080. Everything runs locally in the browser — photos, fonts and samples are vendored, no network requests, and undo/redo plus live preview are built in.

## Run it

```sh
cd app
python3 -m http.server 8000
```

Then open http://localhost:8000/index.html in your browser. (From the repository root, `python3 -m http.server 8000` works too — open http://localhost:8000/app/index.html.)
